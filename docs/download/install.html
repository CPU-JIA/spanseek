Windows 安装

安装跨索 1.0.2

跨索 spanseek 适用于 Windows 10 1809 或更高版本、Windows 11，以及 64 位 Windows 环境。 安装程序不会替你创建知识库；首次启动时，你可以选择数据保存的位置。

下载与版本

请从本页下载安装包。文件名应为 spanseek_1.0.2_x64-setup.exe。安装程序会按当前用户安装， 不需要管理员权限，也不会自动创建开机启动项。

安装包当前未签名

Windows 可能显示“未知发布者”或 SmartScreen 提示。请先核对下方 SHA-256；如果校验值不一致，不要运行安装包。

核对安装包

在 PowerShell 7 中运行下面的命令，将输出与页面上的 SHA-256 逐位比较：

Get-FileHash -Algorithm SHA256 `
  -LiteralPath "$env:USERPROFILE\Downloads\spanseek_1.0.2_x64-setup.exe"
SHA-256 __INSTALLER_SHA256__

安装前确认

  • 系统 Windows 10 1809 或更高版本，或 Windows 11，64 位
  • 运行环境 Microsoft Edge WebView2 Runtime（Windows 11 通常已内置）
  • 硬件 4 GB 内存；程序约需 200 MB，知识库空间另计
  • 网络 记录、阅读、检索与备份无需联网；外部服务按需配置

首次启动

  1. 创建或打开知识库

    选择一个你长期可访问的本地目录。程序不会把知识库藏在安装目录里。

  2. 从六个入口开始

    知识索引、收件箱、资料库、知识图谱、回顾与 AI 助手都在侧栏。 先写一篇笔记，或导入一份材料；点开内容后，在完整工作区继续阅读和写作。

  3. 做一次完整备份

    先确认备份与恢复路径可用。AI 助手中的知识任务可自行填写目标或使用可编辑模板；生成模型、同步和其他外部服务按需配置。

  4. 更新时保留知识库

    升级或卸载程序不会主动删除知识库目录；重要数据仍应保留独立备份。

数据与隐私

默认不会把正文、资料或检索内容发往第三方。只有在你显式配置语义检索或生成服务后， 相关文本才会发送到你选择的服务。密钥保存在 Windows 凭据库；同步为可选功能，默认关闭。
