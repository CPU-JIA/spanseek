# 跨索隐私说明

更新：2026-10-26。适用于跨索 spanseek 1.0.2。

## 默认留在本机

跨索 spanseek 是本地优先的桌面应用。你创建或打开的知识库保存在自己选择的目录中；笔记、资料原件、摘录、标签、视图与备份默认只存在于本机。

应用不要求注册账号，不包含广告 SDK，也不默认上传使用统计。

## 会联网的情况

只有在以下情况，应用才会发起网络请求：

1. **你显式配置并使用了 AI / 向量服务**。相关文本会发送到你选择的供应商；发送范围取决于你执行的操作与配置的渠道。
2. **你配置并开启了同步**。数据会连接到你填写的同步服务地址。
3. **你主动打开网页链接**。应用会把链接交给系统默认浏览器。
4. **安装或更新 WebView2**（如系统缺少运行时）。这一步由安装器或系统完成。

不配置上述服务时，记录、阅读、关键词检索和完整备份都可以离线完成。

## 凭据

AI 渠道与同步相关的密钥保存在 Windows 凭据库中，不写入普通配置文件，也不随完整备份迁移。恢复备份后需要重新配置凭据。

## 诊断

“统计与诊断”导出的诊断包用于排查问题，包含运行环境、版本、知识库统计与脱敏错误信息；不会包含正文、密钥或完整知识库。诊断导出需要你主动触发，不会自动发送。

## 同步

同步是你自行部署或选择的服务。数据在传输与服务器上的安全取决于你的网络与服务配置；请使用可信网络和受控服务器。应用不会把同步数据发送给 spanseek 项目以外的默认云端。

## 数据带走与删除

- 你可以随时使用完整备份把知识库带到新目录或新设备。
- 你可以导出 Markdown / Obsidian 兼容目录。
- 卸载程序不会删除你创建的知识库目录；需要删除时请自行确认目录位置。
- 删除知识库目录是不可逆操作；删除前请先创建完整备份。

## 变更

如果未来版本改变数据流或默认网络行为，会在版本说明中明确写出，并更新本页。
