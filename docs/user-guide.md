# 跨索用户指南

本指南适用于 **跨索 spanseek 1.0.2（Windows x64）**。安装包未签名，下载前请核对 SHA-256；下载与构建信息见仓库 Releases 和安装说明。

记录、阅读、检索与完整备份默认在本机完成。AI 与同步是可选功能，只有在你显式配置后才会连接外部服务。

最短路径见[快速上手](quick-start.md)，当前边界见[已知问题](known-issues.md)，下载与版本见[下载页](download/index.html)。

## 快速上手

1. **安装**：运行 `spanseek_1.0.2_x64-setup.exe`。若 Windows 显示“未知发布者”或 SmartScreen，先在[下载页](download/index.html)核对来源与 SHA-256；只在确认来源后选择“更多信息 → 仍要运行”。不要为安装关闭 Defender 或其他安全软件。
2. **创建知识库**：在欢迎页选择“创建知识库”，选一个专用目录；不要把恢复目标选成现有知识库目录。已有库可从“最近的知识库”打开。
3. **写第一篇笔记**：新建笔记，填写标题和正文，等待状态变为“已保存”；正常退出并重开，确认内容仍在。未提交草稿不算已保存。
4. **导入第一份资料**：在“资料库”选择“导入”，支持 PDF、Word（DOCX/DOC）、Excel（XLSX/XLS）、PowerPoint（PPTX）、EPUB/MOBI、CSV、UTF-8 MD/TXT；也可把文件拖入窗口。PDF 可连续阅读和高亮/旁注，DOCX/DOC 默认进入只读 Word 版式，需要摘录时切到“原文（可摘录）”。
5. **做一次备份**：进入“备份与恢复”，选择新位置并备份，到任务中心确认成功；再用“完整校验”检查包内容。仅选好位置或创建任务不等于备份成功。
6. **做一次恢复演练**：用“恢复到新文件夹”恢复到空目录并打开验证；确认副本可读后再继续日常使用。不要直接复制正在使用的数据库文件代替完整备份。
7. **按需配置 AI**：不配置模型也能编辑、导入、关键词搜索和备份；配置远程模型前先读[AI 与隐私](#ai-与隐私)，测试连接可能产生费用。
8. **升级与退出**：升级前先备份并保留可用的旧安装包；安装/更新/卸载前正常退出应用，后台任务先结束。

## 安装与知识库

运行提供的 Windows 安装程序，然后启动 spanseek。安装版使用随包提供的程序和 PDF 阅读依赖，无需安装 Rust、Node 或 Python。首次安装若缺少 WebView2，安装器需要联网下载；当前包不保证在缺少 WebView2 的离线机器上完成安装。已有 WebView2 的离线机器可以启动；runtime 过旧时，启动横幅会点名当前版本、需更新的版本与受影响的界面特性，诊断页同时给出完整兼容说明。

从欢迎页创建知识库或打开已有知识库，选择保存知识内容的目录。欢迎页“最近的知识库”整行均可点击，名称和路径都能打开；目录不可用时先重新选择有效目录。带搜索框的新首页支持按名称或路径筛选最近库，没有匹配时可清空搜索。未打开知识库时，备份和任务页面可通过“选择知识库”返回欢迎页。打开后也可从知识库菜单切换最近的库。本机偏好默认保存在 `%LOCALAPPDATA%/PKMS`，与知识库目录分开。

从旧版本升级时，覆盖原安装位置即可。知识库、设置、草稿和渠道凭据继续使用原身份；升级前请先创建完整备份并保留可用的旧安装包。

安装后，可在 Windows 的 PDF“打开方式”中选择 spanseek。安装器只增加可选择的应用，不改变现有默认 PDF 阅读器。外部打开的文件先进入阅读流程；临时阅读与保存进知识库按应用内提示选择。

升级前先创建完整备份，并保留可正常使用的旧安装包。请勿用旧版程序强行打开提示“格式版本过新”的知识库；使用匹配的新版程序，或将升级前的完整备份恢复到新目录。

安装、更新和卸载前，请保存内容并从应用正常退出；后台任务仍在运行时也应先结束任务。安装器会拒绝替换正在使用的程序，不会强制关闭编辑窗口。如果安装意外中断，可在应用已退出后重新运行同一安装包修复程序文件；不要删除知识库或草稿。卸载时，「删除应用数据」选项只清理 `%APPDATA%\com.pkms.desktop` 与 `%LOCALAPPDATA%\com.pkms.desktop`（应用标识下的界面与 WebView2 数据）；**不会**删除 `%LOCALAPPDATA%\PKMS`（应用目录、偏好、最近知识与会话根），也**不会**删除你自己创建或打开的知识库目录。需要彻底清除时，请先确认这些目录的位置，再手工删除。

再次启动后若显示欢迎页，点击“最近知识库”中的原知识库，可恢复该库已保存的文档标签与活动面板。

## 工作台与设置

侧栏常驻“知识索引、收件箱、资料库、知识图谱、回顾、AI 助手”六个入口。集合、标签、保存视图和画布按所在功能展开。选集合直接看条目；打开笔记或资料后进入完整内容工作区，返回恢复集合、筛选、分页、选择和滚动位置。自动化、任务中心、回收站、备份与设置位于底部工具区域。

打开的内容保存在侧栏标签页中，关闭标签不会删除内容；`Ctrl`＋`W`关闭当前标签。关闭前若提示保存或操作结果待确认，先处理提示。

按 Ctrl＋Shift＋P 打开命令面板，输入中文或英文筛选新建、打开资料、保存、后退/前进、页面导航和设置；可用命令会显示快捷键提示，↑/↓ 选择，Enter 执行，Esc 关闭。

阅读和编辑默认使用完整主工作区。需要对照时可主动开启分屏；关闭分屏后普通打开仍是整页内容。窗口较窄时，可用面板编号切换两个内容。

窗口变窄或放大界面时，侧栏和笔记列表会按可用空间自动收起；使用“展开侧栏”或“显示笔记列表”打开弹出栏，按Esc返回原入口。自动适配不会改写你保存的列宽偏好。极窄时，格式工具栏和底部状态栏可局部横向滚动。

点击侧栏底部的“设置”，或按 `Ctrl`＋`,`，打开设置弹窗。左侧可切换“外观”“对象类型”“模板”“检索”“清洗”“知识库”“快捷键”和“关于”；外观中选择浅色、深色、跟随系统、界面语言和正文字号。关闭弹窗后继续原来的工作；设置正在处理时请等待结果。

下拉选项可用方向键选择、Enter确认、Esc关闭，长列表在弹层内滚动。带搜索的输入框可查找已有项；提示块类型和模型ID等允许自定义的字段可直接输入。弹窗中的下拉先按Esc关闭选项层，再按Esc关闭弹窗。

## 写笔记与确认保存

新建笔记后可在应用内编辑标题、富文本、图片和对齐表格。一个主窗口最多打开两个内容面板；两个面板打开同一笔记时，共享正文和保存状态。支持的结构会随修订保存，历史恢复会创建一个新修订，不抹去中间历史。

侧栏“新建笔记”旁的箭头可按对象类型新建：笔记、角色、人物、书籍、影视、地点、事件、项目、想法、组织和会面。类型化文章头显示类型、摘要和对应属性；点击类型名可切换类型，旧类型字段仍保留在 YAML 中，切回时恢复显示。类型与属性保存在正文首个 YAML frontmatter，不新增隐藏副本；YAML 无法解析时页面会禁用类型切换并提示回到原文修正，不应把错误属性当作空值。

按 `Ctrl`＋`Shift`＋`P` 打开命令面板，搜索“新建角色”“新建书籍”等即可直接按对象类型创建；创建结果与侧栏类型菜单一致，同样写入 YAML 类型和正文骨架。
设置 →“对象类型”可管理当前知识库的自定义类型：填写中英文名称与说明，选择色调，维护别名、文本/数字/日期/单选属性、双语选择项、默认值和正文分节。类型标识创建后不能更改；保存前有未保存状态，删除类型需要二次确认，已有笔记的 YAML 不会被删除。自定义类型只属于当前知识库；定义已进入 Schema 38 `workspace_metadata`，随完整备份和跨设备同步；旧版仅存本机偏好的定义会迁移一次。

设置 →“模板”可保存可复用的笔记标题和正文结构。模板可绑定一个对象类型，继承该类型的 YAML 默认值和属性；支持双语名称、说明、标题、Markdown 正文，以及 `{{date}}`、`{{time}}`、`{{type}}` 占位符。保存后从侧栏新建菜单的“模板”分组或命令面板“从模板新建：…”直接创建；创建时按当前界面语言选择标题/正文并写入 `template` provenance。空正文使用对象类型的分节骨架，目标类型已不可用时会明确报错而不会静默创建普通笔记。模板同样只属于当前知识库；定义已进入 Schema 38 `workspace_metadata`，随完整备份和跨设备同步。

富格式支持 H1–H6、下划线、多色高亮/字色、上下标，以及双链/嵌入、脚注、提示块、公式和 Mermaid 图表。源码内容可查看与编辑；YAML属性保存在正文中，不会自动修改spanseek标签或状态。Markdown无法保真的组合会明确报错，完整迁移仍使用完整备份。

保存视图的“Frontmatter 自定义属性”可手动输入或从当前匹配笔记发现键名。属性只读取笔记首个 YAML frontmatter 的受限投影，修改仍回到原文 YAML；表格、列表和看板显示属性摘要，日历/时间线可选择某个日期属性作为分组依据，缺失或无效日期的笔记进入“未排期”。属性面板会标出解析失败或截断的只读投影，CSV 导出会追加对应属性列和 `property_warnings`。每个视图最多选择 12 个自定义属性，内置与自定义列合计最多 16 个。

在引用块或提示块的最后一个空段落按Enter，可退出当前层继续写正文；在块内按 `Ctrl`＋`Enter` 可直接到块外继续写。嵌套结构一次退出一层，原块内容保留。编辑提示块时，可搜索已有类型或输入自定义类型，同时修改标题和折叠选项；取消保留原值，应用后可撤销/重做。

画廊卡片展示正文开头的富文本和图片缩略图，打开笔记可查看完整内容。若出现“预览读取失败”或“缩略图读取失败”，仍可打开正文；检查文件可用性后，从该卡片的笔记操作菜单选择“重新读取预览”。预览中的任务、链接和引用用于展示，实际操作请进入笔记。

粘贴大段内容时，若出现确认弹窗，先检查内容再选择“应用”；取消会保留原正文。确认并出现“已保存”前，不能把弹窗里的内容当成已经提交。读写长文时可用 `Ctrl`＋`Home` / `End` 到开头或末尾。

编辑会自动保存。离开前查看保存状态：本机草稿、正在保存、已保存、保存失败和版本冲突含义不同。只有已确认保存的内容才已经提交到知识库；本机未提交草稿不包含在完整备份中。

遇到保存失败，保留当前窗口及草稿，按提示显式重试；继续等待自动保存不代表失败状态已恢复。遇到版本冲突，打开比较可查看知识库当前版本与本地草稿的完整正文和图片；关闭比较会保留草稿。可将草稿另存为新笔记，也可在二次确认后放弃草稿并采用知识库版本。若比较期间任一方发生变化，先重新比较。采用已有版本不会创建额外修订。

若提示操作结果尚待确认，先确认原操作结果，不要重复创建内容。不要通过清理应用数据或浏览器缓存修复保存问题，这会影响本机待恢复记录。

正常关闭窗口时，应用会检查未完成的保存和中文组词。若关闭被阻止，先确认输入法组词或处理提示，再关闭；异常退出后重新打开原知识库，检查恢复状态。

每个本机知识库分别记住窗口位置、尺寸、最大化状态及各面板的笔记滚动位置，正常关闭或切库时确认保存。两个面板可保留同一笔记的不同阅读位置；点击段落引用时优先跳到引用目标。异常退出可能保留的是最近一次已保存的位置。

## 链接、交叉引用与隐藏内容

编辑正文时，普通单击链接用于定位或选择文字；按住Ctrl点击，或在附近的链接工具中选择“打开链接”，可交给系统浏览器。工具中也可编辑、复制地址或移除链接。只读阅读和历史正文可直接点击外部链接；不支持的地址会显示提示。

通过笔记工具栏插入引用，可搜索笔记、资料或摘录，选择整篇、标题、段落或资料页，并按需要设置显示名称和固定修订。编辑时用Ctrl点击引用，阅读时直接点击；定位后可“返回来处”。“本文引用”和反向引用可从两侧查看上下文。固定修订始终指向原版本，目标被删除或位置失效时会显示真实状态，不改指向同名内容。

关系属性可在对象类型中定义，并限制允许关联的对象类型。打开引用侧栏的“关联到这里 / Linked by property”可查看哪些笔记通过 YAML 关系指向当前笔记；“本文引用”“引用了这里”和“关联到这里”分别展示正文引用、反向引用与属性关系。关系选择器支持搜索、分页、IME 中文组词和 ↑/↓/Home/End/Enter/Escape；Esc 关闭选择器并把焦点还给触发按钮，已回收目标会显示状态且不能被重新选中。

批量属性编辑先选择对象类型。文本、数字、日期、单选和关系属性都可批量写入；关系支持添加、替换全部和清空，每篇最多 12 个目标且不能关联自身。部分笔记失败时只重试失败项，已完成笔记不会被重复提交。
行内和块级隐藏内容默认模糊，点击可显现，再次点击恢复隐藏；聚焦显隐控制后也可用键盘操作。显隐只影响当前阅读，不改写正文，重开默认隐藏。原 `%%` 内容及源码保留，普通阅读导出仍按隐藏合同处理；模糊不等于加密。

## 文献引用与 CSL

编辑器“插入”菜单提供“插入文献引用…”和“参考文献列表…”。导入 BibTeX、CSL JSON 或 `.csl` 样式后，可按标题、作者或引用键搜索；一次可选择多条参考文献，并为每条设置页码、章、节、卷、图、注、行、表、公式、词条或自定义定位符。预览确认后按“插入引用”或 `Ctrl`＋`Enter`，正文写入 `[@key, pp. 3-4; @key2, ch. 2]` 形式的纯文本引文簇；重复选择同一引用键会去重。

“参考文献列表…”按当前 CSL 样式显示正文引注预览和文献表。APA、Chicago、GB/T 与导入样式均使用同一成熟 CSL 引擎；note 类样式会按出现顺序编号，相同引用再次出现可按样式显示 ibid。缺失引用键会单独告警并保留原标记。复制或插入文献表前先核对样式；文献表会记住插入时使用的 CSL 样式，再次打开时自动恢复。再次插入会整体更新现有文献表区块，正文其他内容不受影响；若检测到该区块被手工修改，会先提示这些修改将被覆盖，取消不会改动正文。

## 导入资料与摘录

阅读PDF无需先新建笔记。欢迎页的“打开PDF”、侧栏“打开资料”和 `Ctrl`＋`O` 都提供文件入口，也可把 PDF、DOCX/DOC、XLSX/XLS、PPTX、EPUB/MOBI、CSV、Markdown 或 TXT 文件拖入窗口。未打开知识库时，欢迎页的“打开PDF”只列出 PDF；侧栏“打开资料”、`Ctrl`＋`O` 与拖入都接受全部可导入格式（PDF、DOCX/DOC、XLSX/XLS、PPTX、EPUB/MOBI、CSV、Markdown、TXT），PDF 可临时阅读，其余格式先进入“已打开资料”，页面明确显示“尚未保存到知识库”。点击“保存到知识库”选择或创建库，PDF 的当前页码、页内位置、缩放和旋转会一起保留。需要高亮或旁注时先完成保存。临时资料可从“已打开资料”返回，关闭临时资料不会修改外部原文件。

打开 Markdown 资料时默认进入**渲染阅读视图**，标题、列表、表格、代码块、公式、Mermaid 图与内部链接按编辑器同一套渲染规则呈现；右上角的视图开关可切到“原文（可摘录）”，在原文里查找文字、定位块并保存摘录。渲染只读取原件且不超过 1 MiB，不会写回原文件；超过上限或无法渲染时会给出明确提示并留在原文视图。
打开 DOCX 资料时默认进入**Word 版式阅读**：按原件渲染段落、表格、图片、下划线、页眉页脚、编号和分页，不需要安装 Word，也不会改写原文件；版式视图是只读的，需要查找文字或保存摘录时切到“原文（可摘录）”。超过 64 MiB 或无法渲染时会给出明确提示并保留原文阅读。
打开旧版 DOC 资料时，如果本机有 Microsoft Word，会用只读缓存生成精确版式；没有 Word 时明确显示“精确版式不可用”，仍可切到原文阅读、查找和摘录。DOC 原件不会被改写，缓存可以重新检测。

已有知识库时，打开文件会进入当前库的导入流程。也可在“资料库”点击“导入”，在弹窗中选择“本地文件”或“网页链接”；设置“保存到集合（可选）”后，使用“选择并导入”或“保存网页”。文件支持 PDF、DOCX/DOC、XLSX/XLS、PPTX、EPUB/MOBI、CSV、UTF-8 MD/TXT，原件副本保持不变。重复字节复用已有资料，同名不同内容可分别识别，取消选择不会新建空笔记。

文件可一次多选，逐项显示结果；一项失败不影响其他已成功项。“导入记录”可查看进度、失败原因、打开资料或重试原操作，任务中心也保留已受理任务。结果未知时先按提示确认，不要重复创建。未提交的文件在重启后需要重新选择；已经受理的导入可在后台继续。

PDF默认连续竖向阅读，可滚轮浏览，也可输入页码跳转。鼠标位于PDF阅读区时，Ctrl＋滚轮只调整PDF倍率并保留阅读锚点；工具栏提供倍率、适宽/适页和旋转。阅读区外的界面缩放不改变PDF文档倍率。

扫描 PDF 可保存和阅读，1.0 不提供 OCR。部分页面未提取到文字可能是空白页或扫描页，其他已提取文字仍可搜索和摘录；没有文字层时可用区域摘录。网页保存公开正文快照，带URL和抓取时间，不保证登录页面、动态页面或整站归档。损坏、加密或读取失败会显示原因，按提示处理原文件后重试。

MD/TXT 可整份创建为可编辑笔记。先把文件保存为资料，再打开需要的来源版本，选择“创建可编辑笔记”，修改标题并“确认创建笔记”；成功后从页面提示“打开笔记”。如果创建后提示原操作仍需确认，使用“重试原操作”；确认成功会打开已创建的笔记，无需再次创建。

整份转换限不超过 1 MiB 的 UTF-8 MD/TXT。Markdown 保留支持的标题、列表、表格等基础结构；不支持的格式、图片或链接按 Markdown 原文保留并提示，不自动下载图片。TXT 按段落转换。新笔记附带固定来源版本的引用，编辑不写回原件。确认创建前取消不创建笔记；创建后若结果未知，先按提示确认原操作。再次明确创建会产生另一篇独立笔记。

已保存的PDF中选中文字，可在附近选择“高亮”或“旁注”，也可框选区域创建摘录。高亮、原文和批注使用同一份摘录记录并固定来源版本；点击原文高亮定位旁注，旁注的“回到原文”返回对应位置。旁注可修改、取消或移入回收站，保存结果以实际状态为准。定位失效时保留原文及说明，不把相似位置当作原出处。

在摘录列表可选择一条或多条摘录，再“加入同一笔记”，每批最多 100 条。每条原文、批注、页码和固定版本出处会一次追加到目标笔记，之后可继续写解释和结论；原有正文保留。若提示保存仍需确认，按提示继续，重开批次中的任一摘录也可找回待确认批次。

“摘录与批注”顶部可切换“当前资料 / 全库”。当前资料只筛选已加载分页，并同时匹配引文、旁注、页码标签和页码；全库会搜索整个知识库的资料标题、引文与旁注，显示来源和页码，可继续加载更多结果。

全库结果中，同一资料会直接定位；其他资料会打开保存的原版本并聚焦目标摘录。全库结果用于查找，不提供批量选择或就地编辑。

在摘录列表中可用 ↑/↓ 在可见卡片间移动，Enter 定位，Esc 清除当前定位。中文输入法组合期间不会提前发起全库搜索，选词结束后才按最终文本检索。

修改或回收摘录不会自动改写已加入笔记的引文和批注快照；被回收的引用目标会明确显示状态。若固定版本原件无法读取，查看错误提示和已保留的摘录快照，恢复文件可用性后重试；应用不会把引用改指向新版本或相似内容。

已入库PDF会保存页码、页内位置、缩放和旋转；切标签、切库、正常退出后重开可继续阅读。位置保存失败阻止离开或关闭时，先处理提示并重试；异常退出只保证最近已确认保存的位置。

## 组织与回顾

主题／集合用于组织已有内容。同一笔记、资料或摘录可以加入多个集合；移出集合不删除原内容。标签用于交叉分类，多标签筛选按界面条件组合；收件箱的“待整理”“稍后整理”“已整理”状态用于跟踪整理进度。

资料列表可按标题、格式、阅读状态、整理状态、标签和集合组合筛选；多个标签表示同时包含所选标签。没有匹配结果时，可清除筛选查看全部资料。当前筛选在会话内导航返回时保留，重启后恢复默认条件。

点击“批量选择”后勾选资料，可批量添加标签、加入集合、启用或停用检索、移入回收站；结束后用“结束选择”返回普通阅读列表。改变筛选会清除临时选择。批次显示结果待确认时，使用“继续并确认结果”；重开后仍可确认原批次，已完成项不会重复执行，未完成项会单独列出。

笔记列表的“全部类型”可按内置类型、自定义类型或“未分类”筛选；类型筛选可以和标题搜索、标签、排序组合，并随保存视图一起保存。类型筛选变化会从第一页重新查询，旧游标不会混入新的类型范围。

按类型批量编辑笔记前，先确认列表已筛到目标类型；批量属性面板只显示该类型的字段。关系字段的批量修改会为每篇笔记生成独立修订，部分失败可按项重试；类型变化后应重新选择目标，避免把旧类型的选择带入新范围。
保存视图保留筛选、排序和列表／表格布局，删除视图不会删除结果里的对象。归档、停用检索和回收是不同操作：停用检索后原件仍在，但不应进入新的检索和依证回答；回收内容可从回收站恢复。集合回收不连带回收成员，恢复集合也不恢复已单独回收的成员。

回收站可预览内容并单项恢复，或用“选择项目”后“恢复所选”。彻底删除支持单项、“彻底删除所选”和“清空回收站”；清空包含整个回收站，超出当前搜索和已加载列表。确认前核对目标、数量及关联摘录，取消不改变内容。资料仍在回收站时，先恢复资料或与其摘录一同恢复。

彻底删除会移除本库对象、正文历史、整理记录及对应本机草稿/标签，无法从回收站恢复。原件和附件文件、外部原文件、已有备份，以及其他笔记中的独立引文快照仍保留；这项操作不清理磁盘原件。提示结果待确认时，只确认原操作，避免扩大删除范围。

把需要再看的笔记、资料或摘录加入“回顾”。回顾页区分“待回顾”“稍后”“已回顾”“已移出”，可选择“完成回顾”“稍后回顾”“移出回顾”，或设置“下次回顾时间”。这些是手动记录，不表示系统已经测出你的掌握程度。

## 知识任务与语音速记

在 AI 助手进入“知识任务”，也可以从笔记或资料列表带入选中的材料。写下任务要求即可运行，不必先选模板。模板可新增、编辑、复制和删除；应用模板只帮助填写要求，不自动调用模型。

任务保留所用材料版本、最终要求、模型、原始输出与保存记录。打开来源核对后返回同一任务；编辑成果并点击“审阅并保存”，核对提案、明确确认后才写入知识库。模型可能误读事实，原始输出与人工修订应分别看待。模板或原材料后续修改不重写已有任务快照。

通过顶部“语音速记”录音或导入音频，可暂停、继续、回放、定位并修订转写文本。转写需要单独配置 ASR；没有服务时原音频和手工修订仍可保留。审阅后存入收件箱，可导出 SRT/VTT 字幕。采集中关闭窗口或存在未保存输入时，先处理应用提示。

## 搜索、模型与 AI

关键词搜索可离线使用。语义检索需要配置向量服务；支持 Cloudflare、OpenAI、Google Gemini 与 OpenAI 兼容端点。默认已验证链为 Cloudflare `@cf/baai/bge-m3`。更换模型或维度需要重建索引，原索引可回退。生成渠道与向量服务分别配置。

“模型与连接”保留向量服务与原单模型配置入口：

1. 为向量服务填写“向量 API 地址”和令牌，选择“保存并启用 BGE-M3”，按提示重建索引。缺少配置或索引未就绪时，界面会说明语义能力不可用；关键词仍可用。
2. 为生成服务选择接口协议，填写 API 根地址与模型，保存密钥，点击“测试连接”，通过后“保存已验证配置”。支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages；填写服务商提供的完整根地址及其路径前缀，程序不会自动补 `/v1`。
3. 按需要设置 Top-K、阈值、超时和输出预算。进行中的请求保留启动时的配置；修改配置用于后续请求。连接成功只证明服务可调用，不等于回答质量已通过。

命名渠道按以下流程配置：

1. 点击“添加渠道”，选择服务商模板或自定义入口，填写名称与服务地址，点击“保存渠道”。模板包括OpenAI、Anthropic、Gemini、OpenRouter、DeepSeek和Cloudflare Workers AI；核对实际协议与地址，Cloudflare还需填写Account。
2. 保存渠道后，在“渠道密钥”中输入并“保存密钥”。同一渠道内的模型共用该密钥；改地址或协议后，先保存并确认当前渠道，再操作密钥或目录。
3. 使用“获取模型列表”，或“手动添加模型 ID”；设置模型名称和需要的预算，再次“保存渠道”。获取到列表或保存成功，不代表模型已能完成推理；按需要测试模型，测试会发送简短请求并可能计费。
4. 对已保存模型使用“设为默认”，或在Chat/严格回答的模型选择器中选择。严格依证回答要求模型支持“结构化证据回答”；普通文本模型不能用于该模式。修改配置只作用于后续请求，进行中的请求保留启动时的配置。

如保存提示版本冲突，先保留当前输入并按界面处理，不用重复创建渠道规避冲突。旧单模型与本机 Ollama 配置仍保留在折叠区，没有自动迁移成渠道。

密钥保存在 Windows 系统凭据库。备份恢复到新实例后需要重新配置凭据。启用远程服务时，参与处理的文本会发送到相应服务；连接测试也会发送简短请求。

搜索结果中的分数表示对应检索方式的评分，不是答案正确率。关键词模式不承诺跨语言翻译匹配。点击结果核对原文、版本和出处，再据此使用内容。

点击“范围筛选”展开类型、集合、标签、归档等条件。收起筛选区会保留条件，并在标题旁显示范围摘要；修改条件后重新搜索，已有结果仍对应上次提交的范围。

自由 AI 对话可多轮讨论、总结和纠错；严格依证问答只依据所选知识库范围，没有足够证据时应拒答。两种模式的依据不同，使用前确认当前模式及资料范围。生成内容可能有误，关键事实仍需查看原始出处。

自由对话输入区的“＋”用于“添加资料片段”：搜索原文，展开结果核对具体内容，再加入本次消息。已选资料显示在输入区，可逐项移除。旁边的参数按钮打开“范围与运行选项”，可设置对话用途、是否检索知识库、检索范围和运行预算。改变检索范围后，按提示在新范围重新选择资料。

输入框中 `Enter` 换行，`Ctrl`＋`Enter` 或发送按钮提交消息。若运行参数不是允许范围内的整数，页面会提示修改，不会发送请求。切换会话时，未发送文字和已选资料按会话分别保留；“新对话”的草稿与已有会话分开。

生成结果若显示取消、失败或截断，已有片段不代表完整答案。未知请求结果应先按界面确认，不要立即重复发送可能产生费用的请求。

### AI 与隐私

- **默认不外发**：未配置远程服务或未同意“文本可发送到配置的远程服务”时，应用不会把检索/问答文本发到远程端点；关键词搜索和本地编辑仍可用。
- **同意后只发配置端点**：启用后，参与处理的文本会发送到你配置的服务；撤销同意后立即停止新的远程请求。连接测试也会发送简短请求并可能计费。
- **密钥位置**：API 密钥保存在 Windows 系统凭据库；完整备份、Markdown/HTML 导出和诊断包不包含密钥。恢复到新实例后需要重新配置凭据。
- **本地服务**：本机 Ollama 等本地端点按本地配置处理，不经过远程同意开关；仍要确认模型与服务的实际数据路径。
- **不要把密钥写进笔记、文件名或诊断说明**。若怀疑泄漏，先在服务商处轮换密钥，再删除本机渠道配置。
- **AI 输出可能出错**：严格依证回答会尽量引用证据，但引用有效性、拒答和事实正确性仍需人工核对。重要结论请回到原文。

## 审阅提案与形成输出

把摘录、回答或 AI 草稿用于新笔记，或为已有笔记创建修改提案。应用前先检查目标、拟修改内容和引用，再明确应用。若目标笔记已变化，旧提案不能覆盖新正文，应基于当前版本重新审阅。

笔记可导出 Markdown 或 HTML，并附带结构化内容、引用及格式损失说明。普通导出便于阅读和交换，不替代包含历史、资料及附件的完整备份。导出后查看任务结果和损失报告，确认接收工具能呈现所需内容。

## 完整备份与恢复

1. 打开知识库，确认需要保留的编辑已保存。进入“备份与恢复”，点击“选择位置并备份”，使用新的文件名。
2. 到任务中心确认备份成功。仅选好位置或已创建任务不表示备份完成。
3. 点击“选择备份包”读取包信息，再运行“完整校验”。读取清单还没有检查全部内容。
4. 点击“恢复到新文件夹”，选择新目录。恢复时会重新校验，只写入新目录；任务成功后打开恢复的知识库。

校验和恢复无需先打开知识库。完整包包含已提交正文、修订、历史图片、资料原件及版本、组织关系、引用和已支持的 AI／回顾记录；已配置的渠道与模型配置也会包含在内。本机未提交草稿、凭据及窗口偏好不随包迁移；恢复副本使用独立本机实例，源库与副本的草稿不混用。恢复后重新配置所需凭据，派生检索索引可重新建立。

对象类型和笔记模板属于知识库级配置，会随完整备份保存，也会在已配对设备间同步。两端同时修改配置时，“备份与恢复”会保留待处理冲突；打开页面即可看到，不必先手工拉取。选择“保留本机并推送”或“采用远端”前都会二次确认；采用远端后模板与对象类型立即刷新。不要在没有核对时覆盖远端配置。
不要直接复制正在使用的数据库文件来代替完整备份，也不要把恢复目标选为现有知识库目录。任务中断后先重新启动并查看原任务或恢复操作的状态；取消与完成以最终记录为准。

## 任务、诊断与常见问题

“任务中心”显示排队、运行、成功、失败或取消及真实阶段。“原件已保存”表示原件已保留，后续解析是否完成仍以任务最终结果为准。离开任务页不会取消后台任务。失败后查看错误说明，修正输入、权限或配置，再使用任务提供的重试入口。

在“统计与诊断”中选择类别，点击“预览导出内容”，确认后“选择位置并导出”。诊断包保存到本机，不自动上传；默认不包含笔记正文、模型输入、密钥或本机路径。若信息变化提示重新预览，刷新预览后再导出。统计数量来自实际记录，但不替代完整备份校验。

| 安装时缺 WebView2        | 安装器需要联网下载 runtime，或先在机器上安装 WebView2 Runtime；离线缺 runtime 不保证安装成功。           |
| DOCX 版式与 Word 不一样  | 版式视图是只读近似排版；需要摘录切“原文”，需要精确版式用 Word 打开原件。                                 |
| AI 会不会上传笔记        | 未同意远程处理时不外发；同意后只把参与请求的文本发到配置端点。详见[AI 与隐私](#ai-与隐私)。              |
| 旧版打不开知识库         | 新 schema 会拒绝旧程序写入；用匹配的新版程序，或把升级前完整备份恢复到新目录。                           |

界面缩放可用 `Ctrl`＋`+`／`-`、阅读区外的 `Ctrl`＋滚轮，`Ctrl`＋`0` 复位；PDF阅读区内的Ctrl＋滚轮由PDF局部缩放处理。`Alt`＋左／右及鼠标侧键用于页面访问历史，与笔记撤销／重做分开。
