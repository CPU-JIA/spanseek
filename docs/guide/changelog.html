跨索 spanseek CHANGELOG

面向用户的版本记录。安装包、SHA-256 与系统要求见下载页，当前边界见已知问题。

1.0.1 — 2026-11-05

  • 六个常驻入口与完整内容工作区；返回保留集合、筛选、分页和滚动，支持主动分屏。
  • 知识任务支持自定义要求、可选模板、固定来源、真实生成、编辑审阅、明确保存和历史追溯。
  • 标签字典与分配支持同步、冲突比较、权限检查、删除影响和待依赖恢复。
  • 语音速记支持原音频、回放、转写修订、字幕与手机捕获；录音关闭和恢复保护完善。
  • 新增 Office、EPUB/MOBI、CSV 等阅读支持和捆绑 OCR；实际格式限制见格式支持表。
  • 完善保存视图、图谱/画布、研究/自动化、任务中心、错误重试与完整备份恢复。
  • 官网更新真实界面和 50 秒有声演示；安装包仍未签名。

1.0.0 — 2026-10-22

首个 Windows 本地交付版本。Windows x64，单用户，本地优先。

品牌与官网

  • 品牌标识更新为墨黑底、暖白 S 路径与暖金落点，桌面、官网、favicon 与移动 PWA 同步。
  • 官网新增 50 秒有声产品电影，包含中文旁白、背景音乐、轻音效与中文字幕；用户点击后有声播放。

记录与阅读

  • 新建、编辑与保存笔记，支持标题、段落、标题层级、列表、任务列表、引用、代码块、表格、图片、公式与 Mermaid 图表。
  • 导入 PDF、DOCX、Markdown 与 UTF-8 TXT；原件按内容寻址保存，不被编辑覆盖。
  • PDF 阅读器支持目录、页码、缩放、适宽、摘录与阅读位置保存。
  • DOCX 使用内置 Word 版式渲染；需要摘录时可切换到原文视图。
  • 长文档支持标题折叠、折叠全部/展开全部与按笔记持久化。

组织与找回

  • 笔记画廊、列表、集合、标签与属性编辑。
  • 表格、看板、日历、时间线与画布视图。
  • 画布只保存布局与引用，不复制正文；支持拖拽、缩放、适应画布与 SVG/JSON 打印导出。
  • 双向链接、反链上下文与 wiki 嵌入。
  • 中文全文检索、关键词高亮、最近搜索与可选语义检索；语义未配置时明确显示关键词回退。
  • 命令面板、快捷键、撤销/重做、批量整理与侧栏拖拽。

AI 与自动化

  • 自由对话、严格依证问答与提案审阅。
  • AI 只能提案；变更摘要默认折叠，只有明确应用后才会写入正文。
  • 近 30 天用量与费用只显示真实数据；未配置参考单价时不伪造金额。
  • 自动化变更集与研究任务；支持应用、跳过、拒绝、撤销与取消。
  • 同步状态覆盖离线、连接中、冲突与恢复；高风险操作使用应用内原生确认框。

数据与可靠性

  • 完整备份包含笔记、修订、资料原件、摘录、标签、视图与提案；支持校验和恢复到新目录。
  • 保存冲突、读取失败、画布保存失败与同步离线均显示原因和可执行下一步。
  • 设置页区分“已保存/未保存”，并提供恢复默认值。
  • 启动画面、欢迎页与“关于”使用统一品牌标记，显示真实版本、平台、知识库格式与 WebView2 版本。
  • 键盘焦点、可访问名称、Esc 返回焦点与对话框焦点陷阱覆盖主要界面。
  • 100% / 125% / 200% 缩放、深色模式与英文界面完成一轮矩阵检查。

当前边界

  • 安装包未签名；Windows 可能显示“未知发布者”或 SmartScreen。
  • 仅支持 Windows 10 / 11 x64；依赖 WebView2。
  • 没有自动更新；升级前请创建完整备份。
  • PDF 扫描件不提供 OCR。
  • 同步需要自行配置服务；移动端只提供配套捕获与续读。
  • 详细边界与未覆盖环境见已知问题。
