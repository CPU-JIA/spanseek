跨索快速上手

适用：跨索 spanseek 1.0.1（Windows x64）。目标是十分钟内完成第一次有用记录，不替代用户指南、已知问题或安装说明。

1. 核对并安装

  1. 从安装说明取得 spanseek_1.0.1_x64-setup.exe。

  2. 在 PowerShell 中核对 SHA-256：

    Get-FileHash -Algorithm SHA256 `
  -LiteralPath "$env:USERPROFILE\Downloads\spanseek_1.0.1_x64-setup.exe"

  3. 与下载页显示的哈希逐位比较；不一致就不要运行。

  4. 当前安装包未签名。Windows 可能显示“未知发布者”或 SmartScreen；确认来源和哈希后再选择“更多信息 → 仍要运行”。不要为安装关闭 Defender。

安装程序按当前用户安装，不需要管理员权限。Windows 10 需要 Microsoft Edge WebView2 Runtime；Windows 11 通常已内置。

2. 创建知识库

启动跨索，在欢迎页选择“创建知识库”，再选择一个专用目录。

  • 知识库目录由你决定，程序不会把它藏进安装目录。
  • 已有知识库可从“最近的知识库”打开。
  • 不要把恢复目标选成正在使用的知识库目录。

3. 写第一篇笔记

选择“新建笔记”，填写标题和正文。底部状态变为“已保存到知识库”后，正常退出并重新打开，确认内容仍在。

未提交的草稿不算已保存；切换文档或退出前先看一眼保存状态。

4. 导入第一份资料

进入“资料库”，选择“导入”，或把文件拖入窗口。支持：

  • PDF
  • Word（DOCX / DOC）、Excel（XLSX / XLS）、PowerPoint（PPTX）
  • EPUB / MOBI、CSV
  • Markdown（UTF-8）
  • TXT（UTF-8）

原件按内容寻址保存，不会被编辑覆盖。PDF 可阅读、缩放、适宽、按目录跳转并保存摘录；DOCX 默认进入只读 Word 版式，需要摘录时切换到“原文（可摘录）”。

5. 做一次完整备份

进入“备份与恢复”，选择一个新的位置并创建完整备份。完成后在任务中心确认成功，再用“检查或恢复备份”做一次完整校验。

完整备份包含笔记、修订、资料原件、摘录、标签、视图与提案。仅选好位置或创建任务，不等于备份成功。

6. 做一次恢复演练

用“恢复到新文件夹”恢复到空目录，再打开副本确认可读。不要直接复制正在使用的数据库文件来代替完整备份。

7. 按需配置 AI 与第二台设备

不配置 AI 也能记录、阅读、关键词检索和备份。

  • AI：在“设置 → 模型与连接”中配置生成或向量服务。只有你显式配置后，相关文本才会发往该服务；测试连接可能产生费用。
  • 同步：在“备份与恢复 → 实时同步”中填写同步服务地址并配对。同步是可选功能，默认关闭；移动端提供配套的捕获、录音与续读。

遇到问题

  • 安装或启动失败：先确认 WebView2 已安装，并检查安装包哈希。
  • 资料无法导入：确认格式、文件是否损坏、是否加密，以及大小是否超过限制。
  • 保存冲突：保留当前输入，按界面提示处理，不要重复创建副本。
  • 需要带走数据：使用完整备份，或从“导出”生成 Markdown / Obsidian 兼容目录。

更多说明见用户指南与已知问题。
