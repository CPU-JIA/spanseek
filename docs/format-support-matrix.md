# spanseek 1.0.1 格式支持表

本表登记当前版本支持的格式与边界，不把“能够导入”写成“无损理解”。每个“部分支持”都附已知损失；未实测的组合不冒充通过。

等级定义：

- **完整**：导入、阅读、摘录、备份/恢复全链有证据，且没有已知内容损失。
- **部分**：主链可用，但有明确列出的损失或不支持项。
- **仅引用**：只保留指向原件的引用/计数，不进入正文能力。
- **未验**：实现可能存在，但当前版本没有可复现证据。

说明：资料随完整备份与恢复，不提供单篇 Markdown 导出；笔记提供 Markdown / HTML / DOCX / PDF 与完整包导出。

## 1. 资料格式

| 形态                | 导入                          | 阅读                                              | 摘录              | 随完整包恢复 | 等级与边界                                            |
| ------------------- | ----------------------------- | ------------------------------------------------- | ----------------- | ------------ | ----------------------------------------------------- |
| TXT                 | 是                            | 原文/文本阅读                                     | 是（块锚）        | 是           | 完整（按 UTF-8 文本）                                 |
| Markdown            | 是（原件不可变）              | 渲染 + 可摘录原文                                 | 是（块锚）        | 是           | 部分：来源内语法按文本保留，渲染失败回原文            |
| HTML                | 是（正文提取）                | 是                                                | 是                | 是           | 部分：脚本/样式/交互不执行，原件保留                  |
| PDF                 | 是                            | PDFium 连续阅读、目录、缩放、适宽/适页            | 字符/区域         | 是           | 部分：复杂多栏、跨页表格仍有损失                      |
| DOCX                | 是                            | Word 精确版式（Word 可用）或内置语义渲染          | 是（原文视图）    | 是           | 部分：复杂分页、字体替换与嵌入对象可能不同            |

| XLSX                | 是                            | 工作表、公式缓存/来源、日期/时间/百分比、合并范围 | 是                | 是           | 部分：图表/透视表等对象不进入正文                     |
| XLS（BIFF8）        | 是                            | 多工作表、单元格、日期、公式来源、合并文本        | 是                | 是           | 部分：宏、图表对象与复杂格式不执行；引用修复已 vendor |
| CSV                 | 是                            | 表格文本阅读                                      | 是                | 是           | 部分：编码与分隔符按导入检查，不推断业务类型          |
| PPTX                | 是                            | 演示顺序、表格、图片、图表缓存、SmartArt、备注    | 是                | 是           | 部分：动画、切换、嵌入媒体和精确版式不进入阅读投影    |

| MOBI                | 是（DRM 明确拒绝）            | 封面、目录、章节、正文图片                        | 是                | 是           | 部分：AZW3/DRM/复杂排版不承诺                         |
| 扫描 PDF + OCR      | 是                            | 显示 OCR 状态并阅读                               | 是（词框映射）    | 是           | 部分：中文质量、低质扫描与手写需实机验收              |
| PDF 表格            | 是（字符几何）                | 表格预览 + Markdown 复制                          | 是（bbox 回原文） | 是           | 部分：合并单元格、跨页表格不保证                      |

## 3. 检索与索引

| 能力               | 状态 | 说明                                         |
| ------------------ | ---- | -------------------------------------------- |
| 中文分词与繁简折叠 | 支持 | FTS 与查询使用同一规范化                     |
| 关键词 + 语义融合  | 支持 | 无语义配置时明确回退关键词，不伪造命中       |
| 块检索             | 支持 | 稳定块 ID、别名、keyset 分页、引用计数       |
| 10k/50k 图谱布局   | 支持 | 视口裁剪、路径高亮、facet/AND 标签与性能探针 |
| 搜索历史           | 支持 | 按物理 workspace 隔离，不保存结果正文        |

## 4. 明确边界

- 不可执行宏、脚本、远程图片、外部嵌入或 DRM 内容。
- Office/EPUB 阅读是只读投影，不承诺与 Office/阅读器逐像素一致；可摘录原文始终独立保留。
- OCR 仍需真实设备上的中文质量、第三方读屏与安装包验收，不能由单元测试代替。
- 同步与协作需要配置服务和设备权限；不同物理设备、网络与辅助技术的覆盖边界见[已知问题](known-issues.md)。
